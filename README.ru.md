# Squeeze

[English](README.md) · [Русский](README.ru.md)

**Освобождает место на диске Mac, ничего не удаляя.** Squeeze показывает ваши программы по размеру,
считает, насколько каждая уменьшится, и сжимает её встроенным в APFS сжатием. Программы остаются на
месте и работают как обычно, просто занимают на диске меньше. Пример: игра весом 72 ГБ стала занимать
38 ГБ.

Папки программы Squeeze находит сам: саму программу, её данные в `~/Library/Application Support` и
известные дополнительные места, например файлы поддержки устройств Xcode или Android SDK. Игры Steam
показываются по отдельности. Любую другую папку можно добавить вручную.

> **Статус:** ранняя версия. Сборка и тесты запускаются при каждом изменении, но программу пока
> пробовали немногие. Прочитайте [Ограничения](#ограничения).

## Установка

1. Скачайте **`Squeeze-<версия>.zip`** со страницы [Releases](https://github.com/yuran1174/squeeze/releases)
   (в разделе «Assets», не «Source code»), откройте его и перенесите `Squeeze.app` в **Программы**.
2. Откройте Squeeze. В первый раз macOS его остановит, потому что программа не подписана платным
   аккаунтом разработчика Apple ([почему](#почему-macos-предупреждает)). Разрешите один раз:
   - **macOS 15 Sequoia и новее:** закройте предупреждение, откройте **Системные настройки →
     Конфиденциальность и безопасность**, прокрутите вниз до «Squeeze заблокирован…», нажмите
     **Всё равно открыть** и подтвердите паролем.
   - **macOS 13–14:** правый клик по `Squeeze.app` → **Открыть** → **Открыть**.

Больше ничего ставить не нужно. Squeeze откроет окно со списком программ, а также живёт в строке меню.

Требования: macOS 13 или новее, диск APFS (все Mac примерно с 2017 года).

<details>
<summary>Вместо шага 2 через Терминал</summary>

```bash
xattr -dr com.apple.quarantine /Applications/Squeeze.app
```
</details>

## Как пользоваться

Интерфейс пока на английском, названия кнопок ниже даны так, как они выглядят в программе.

1. Откройте Squeeze. Он измерит каждую программу: размер на диске и **сколько освободит сжатие**
   (оценка по образцу в памяти, ничего не меняется). Можно сортировать по любой колонке и искать по
   названию.
2. Нажмите **Compress** напротив программы. Прогресс виден в строке таблицы и в строке меню.
3. **Decompress** возвращает программе исходный размер.

macOS может попросить две вещи:

- **«Управление приложениями».** macOS защищает программы от изменения другими программами. При первом
  сжатии Squeeze покажет кнопку, которая откроет **Конфиденциальность и безопасность → Управление
  приложениями**; включите там Squeeze один раз.
- **Пароль администратора.** Программы из App Store (Xcode, Pages…) и некоторые установщики
  принадлежат системе. У них кнопка **Compress…**, и macOS спросит пароль один раз на каждое сжатие.

Squeeze держит сжатые программы сжатыми: обновления записывают новые файлы несжатыми, поэтому раз в
30 минут (на зарядке, пока вы не за компьютером) он дожимает новые файлы. Программы, которым нужен
пароль, в фоне не трогаются. В строке меню видно, что происходит и что уже сжато.

### Что хорошо сжимается

| Хорошо сжимается | Почти не меняется |
| --- | --- |
| Игры, игровые движки, Xcode, Android SDK | Фото, видео, музыка |
| Большие программы (Adobe, офисные пакеты, IDE) | ZIP, DMG и другие архивы |
| Старые проекты, сохранённые `node_modules` | Большинство весов нейросетей |
| Текст, логи, наборы данных в CSV/JSON | Файлы, которые постоянно перезаписываются (диски виртуальных машин, базы данных) |

В папках с данными программ кэши, базы данных и логи пропускаются: программы постоянно их переписывают.

## Настройки

В строке меню → Settings.

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Keep programs compressed — держать сжатыми | вкл | Раз в 30 минут дожимать новые файлы того, что уже сжато |
| Only when plugged in — только на зарядке | вкл | Не работать в фоне от батареи |
| Only after N min without input — после N минут простоя | 5 | Ждать, пока вы не пользуетесь Mac |
| Only when N MB or more are new — порог новых данных | 100 МБ | Не запускаться ради пары мелких файлов |
| Show Steam games — показывать игры Steam | вкл | Показывать установленные игры Steam |
| Open at login — запуск при входе | выкл | Запускать Squeeze при входе (только в строке меню, без окна) |

Настройки хранятся в `~/Library/Application Support/Squeeze/settings.json`.

## Безопасность

- Сжатие без потерь и обратимо; содержимое файлов и подписи программ остаются действительными
  (проверяется при каждой сборке на сжатой копии настоящей подписанной программы).
- Программу не трогают, пока она открыта; игру Steam — пока Steam её устанавливает или обновляет.
  Это проверяется перед каждой партией, а не только в начале.
- Файлы обрабатываются небольшими партиями (64 файла или 256 МБ), поэтому остановка не оставит файл
  недоделанным.
- Системные папки, целые диски, домашнюю папку, `~/Library`, iCloud Drive и другие облачные папки нельзя
  добавить как папку.
- Перед распаковкой Squeeze проверяет, хватит ли свободного места.

## Почему macOS предупреждает

Без предупреждения Apple открывает только программы, подписанные платным Developer ID ($99 в год) и
проверенные Apple (нотаризация). Squeeze бесплатный и пока так не подписан, поэтому macOS один раз
просит его разрешить. Исходный код открыт, и каждая версия собирается из него на GitHub Actions
([журнал сборок](https://github.com/yuran1174/squeeze/actions)).

## Для игроков Steam: скрипт без приложения

Скрипт для Терминала, который делает фоновую часть для игр Steam, если вам удобнее launchd, чем
программа в строке меню. Он берёт инструмент сжатия из Squeeze.app или `afsctool` из Homebrew.

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
./scripts/squeeze-steam.sh --list              # игры, размер на диске, доля сжатого
./scripts/squeeze-steam.sh --app 570 --force   # сжать одну игру сейчас (570 = Dota 2)
./scripts/install-agent.sh                     # раз в 2 часа дожимать новые файлы сжатых игр
./scripts/install-agent.sh --remove            # убрать фоновое задание
```

## Сборка из исходников

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
./scripts/build-afsctool.sh           # инструмент сжатия из его исходников (нужен Homebrew для сборки)
swift test                            # тесты
UNIVERSAL=1 ./scripts/build-app.sh    # dist/Squeeze.app и zip для Apple Silicon и Intel (нужен Xcode)
```

`Sources/SqueezeCore`: поиск программ и их папок, сканирование, прогноз, запуск инструмента сжатия (в
том числе с правами администратора), библиотеки Steam, настройки. `Sources/Squeeze`: приложение на
SwiftUI. Каждый пуш собирается и тестируется на GitHub Actions; тег вида `v0.2.0` публикует релиз.

## Ограничения

- Только диски APFS (и HFS+); не exFAT и не сетевые диски.
- Данные программ из App Store с песочницей (`~/Library/Containers`) защищены macOS и не трогаются.
- Некоторые программы и античиты не любят изменения файлов на диске. Содержимое остаётся прежним,
  но если что-то ведёт себя странно, распакуйте программу.
- Интерфейс пока на английском.

## Планы

- Иконка; русский интерфейс.
- Другие лаунчеры (Epic, Battle.net), бутылки CrossOver и Whisky.
- Общие данные о том, как сжимаются популярные программы.
- Подпись Developer ID и нотаризация: без предупреждения при первом запуске, затем Homebrew cask.

## Лицензия и авторы

Squeeze распространяется под лицензией MIT. Сжатие выполняет [afsctool](https://github.com/RJVB/afsctool)
его собственных авторов под лицензией GPL-3. В Squeeze.app входит его неизменённая копия, собранная
из опубликованных исходников, и запускается как отдельная программа; её лицензии и точный источник
указаны в `Squeeze.app/Contents/Resources/ThirdParty/afsctool`.
