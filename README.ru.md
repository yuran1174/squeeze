# Squeeze

[English](README.md) · [Русский](README.ru.md)

Squeeze освобождает место на диске в macOS с помощью **прозрачного сжатия APFS**. Файлы остаются на
месте и открываются как обычно, но занимают на диске меньше. Пример: Dota 2 сжалась с 72 до 38 ГБ.

Это аналог CompactGUI для Mac, в первую очередь для игр. Программа находит игры Steam, показывает,
сколько удастся освободить, сжимает одной кнопкой и **держит игры сжатыми после обновлений**
(обновление игры записывает новые файлы несжатыми).

> **Статус:** ранняя версия. Код написан, но сборка и тесты на GitHub только начали запускаться
> автоматически. Возможны шероховатости, прочитайте [Ограничения](#ограничения).

## Как это работает

APFS умеет хранить файл сжатым и распаковывать его на лету при чтении. Программы видят тот же файл
того же размера, поэтому игры работают без изменений. Плата за это — немного процессора при чтении.
На современных Mac это обычно незаметно, а на медленном диске загрузка из сжатого файла может быть
даже быстрее.

Сжатие делает не сам Squeeze, а [afsctool](https://formulae.brew.sh/formula/afsctool) (LZFSE), который
ставится через Homebrew. У afsctool лицензия GPL-3, поэтому Squeeze его не встраивает, а запускает
вашу установленную копию. Код самого Squeeze — под лицензией MIT.

Перед сжатием Squeeze может **оценить выигрыш**, ничего не меняя: он читает часть файлов и сжимает её
в памяти блоками по 64 КиБ, как это делает APFS. Игры, где много уже сжатого видео и архивов,
выигрывают мало, остальные — много.

## Установка

1. Установите afsctool:

   ```bash
   brew install afsctool
   ```

2. Получите приложение: скачайте `Squeeze-<версия>.zip` со страницы
   [Releases](https://github.com/yuran1174/squeeze/releases) (или последнюю сборку со страницы
   [Actions](https://github.com/yuran1174/squeeze/actions)), распакуйте и переместите `Squeeze.app` в
   «Программы». Или соберите сами (ниже).

3. **Первый запуск.** Приложение подписано ad-hoc, без Apple Developer ID, поэтому macOS предупредит о
   неизвестном разработчике. Нажмите правой кнопкой на `Squeeze.app` → **Открыть** → **Открыть**
   или один раз выполните:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Squeeze.app
   ```

Squeeze живёт в строке меню, значка в Dock у него нет.

Требования: macOS 13 или новее, диск с APFS (все Mac примерно с 2017 года).

## Приложение в строке меню

- Список ваших игр Steam (все библиотеки, включая внешние диски) и папок, которые вы добавили: размер
  на диске, размер для программ и прогноз выигрыша.
- Кнопки **Сжать**, **Распаковать** и **Стоп** с прогрессом. Файлы обрабатываются небольшими партиями
  (64 файла или 256 МБ), поэтому остановка никогда не прерывает файл посередине.
- **Дожимать после обновлений**: раз в 30 минут Squeeze ищет новые несжатые файлы в уже сжатых играх и
  папках и сжимает их.
- История: что сжато и сколько места освобождено, а также уведомления.

Настройки:

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Дожимать после обновлений | вкл | Фоновая работа для уже сжатых игр и папок |
| Только на зарядке | вкл | Не работать в фоне от батареи |
| Только после N минут простоя | 5 | Ждать, пока вы не пользуетесь Mac |
| Порог новых данных | 100 МБ | Не запускаться, пока не накопится столько новых данных |
| Запуск при входе | выкл | Запускать Squeeze при входе в систему |

Настройки хранятся в `~/Library/Application Support/Squeeze/settings.json`.

## Фоновый скрипт (приложение не нужно)

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
./scripts/squeeze-steam.sh --list              # игры, размер на диске, доля сжатого
./scripts/squeeze-steam.sh --app 570 --force   # сжать одну игру сейчас (570 = Dota 2)
./scripts/squeeze-steam.sh --all --force       # сжать все установленные игры
./scripts/install-agent.sh                     # раз в 2 часа дожимать новые файлы сжатых игр
./scripts/install-agent.sh --remove            # убрать фоновое задание
```

По умолчанию скрипт трогает только игры, которые уже сжаты больше чем наполовину, и только на зарядке,
когда Mac не используется. `--force` отключает проверку зарядки и простоя. Лог:
`~/Library/Logs/squeeze.log`.

## Безопасность

- Игру **никогда не трогают, пока она запущена или пока Steam её устанавливает или обновляет**. Это
  проверяется перед каждой партией, а не только в начале.
- Squeeze отказывается работать с системными папками, самим `/Volumes`, вашей домашней папкой,
  `~/Library`, а также с iCloud Drive и другими облачными папками.
- Сжатие без потерь и обратимо. Файлы, которые afsctool не может сжать (используются, нет прав),
  остаются как есть.
- Перед распаковкой проверяется, хватит ли свободного места.

### Как отменить сжатие

В приложении нажмите **Распаковать** или выполните в Терминале:

```bash
afsctool -d "/путь/к/папке"
```

Убедитесь, что свободного места хватает: папка вернётся к полному размеру.

## Сборка из исходников

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
swift test                            # тесты (тесты настоящего сжатия требуют afsctool)
./scripts/build-app.sh                # dist/Squeeze.app и zip для вашей архитектуры
UNIVERSAL=1 ./scripts/build-app.sh    # Apple Silicon и Intel (нужен полный Xcode)
```

Swift-пакет для macOS 13+: `Sources/SqueezeCore` (библиотеки Steam, сканирование, прогноз, afsctool,
настройки) и `Sources/Squeeze` (приложение в строке меню на SwiftUI). Каждый пуш собирается и
тестируется на GitHub Actions (`.github/workflows/build.yml`); тег вида `v0.1.0` публикует релиз.

## Ограничения

- Сжатие помогает только тем файлам, которые сжимаются. Видео, аудио и готовые архивы почти не меняются.
- Обновления и проверка файлов в Steam записывают файлы несжатыми; Squeeze сожмёт их позже.
- Некоторые игры, античиты и лаунчеры не любят изменённые файлы. Сжатие не меняет содержимое, но если
  игра ведёт себя странно, распакуйте её.
- Пока поддерживаются только игры Steam и папки, добавленные вручную.
- Приложение не нотаризовано (см. [Установка](#установка)).
