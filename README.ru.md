# Squeeze

[English](README.md) · [Русский](README.ru.md)

**Освобождает место на диске Mac, ничего не удаляя.** Squeeze сжимает папки встроенным в APFS сжатием:
файлы остаются на месте и открываются как обычно, просто занимают на диске меньше. Пример: папка
игры весом 72 ГБ стала занимать 38 ГБ.

Выберите папку, посмотрите, сколько освободится, нажмите **Compress**. Squeeze также может держать
папки сжатыми, когда в них появляются новые файлы (например, после обновления программы или игры).

> **Статус:** ранняя версия. Сборка и тесты запускаются при каждом изменении, но программу пока
> пробовали немногие. Прочитайте [Ограничения](#ограничения).

## Установка

1. Скачайте `Squeeze-<версия>.zip` со страницы [Releases](https://github.com/yuran1174/squeeze/releases),
   откройте его и перенесите `Squeeze.app` в **Программы**.
2. Откройте Squeeze. В первый раз macOS его остановит, потому что программа не подписана платным
   аккаунтом разработчика Apple ([почему](#почему-macos-предупреждает)). Разрешите один раз:
   - **macOS 15 Sequoia и новее:** закройте предупреждение, откройте **Системные настройки →
     Конфиденциальность и безопасность**, прокрутите вниз до «Squeeze заблокирован…», нажмите
     **Всё равно открыть** и подтвердите паролем.
   - **macOS 13–14:** правый клик по `Squeeze.app` → **Открыть** → **Открыть**.

Всё, больше ничего ставить не нужно. Squeeze появится в строке меню (значка в Dock у него нет).

Требования: macOS 13 или новее, диск APFS (все Mac примерно с 2017 года и большинство внешних
дисков, отформатированных на Mac).

<details>
<summary>Вместо шага 2 через Терминал</summary>

```bash
xattr -dr com.apple.quarantine /Applications/Squeeze.app
```
</details>

## Как это работает

APFS умеет хранить файл сжатым и распаковывать его на лету при чтении. Программы видят тот же файл
того же размера, поэтому в них ничего менять не нужно. Плата — немного процессорного времени при
чтении; на современных Mac это обычно незаметно.

Прежде чем что-то менять, Squeeze **оценивает выигрыш**: читает часть файлов и сжимает её в памяти
так же, как это сделала бы APFS.

### Что стоит сжимать

Большие файлы, которые часто читаются, но редко перезаписываются:

| Хорошо сжимается | Почти не меняется |
| --- | --- |
| Игры (игры Steam находятся автоматически) | Фото, видео, музыка |
| Старые проекты, `node_modules`, сохранённые кэши сборки | ZIP, DMG и другие архивы |
| SDK, инструменты разработки, папки с данными программ | Большинство весов нейросетей |
| Текст, логи, наборы данных в CSV/JSON | Файлы, которые постоянно перезаписываются (диски виртуальных машин, базы данных) |

Когда программа перезаписывает сжатый файл, новая версия сохраняется несжатой. Поэтому Squeeze
умеет дожимать папки в фоне.

## Как пользоваться

- **Add Folder…** или перетащите папку на список. Squeeze покажет размер на диске, размер для
  программ и сколько освободит сжатие.
- **Compress**, **Stop**, **Decompress** (сжать, остановить, распаковать). Файлы обрабатываются небольшими партиями (64 файла или
  256 МБ), поэтому остановка не оставит файл недоделанным.
- **Found automatically** (найдено автоматически): установленные игры Steam из всех библиотек, включая внешние диски.
  Можно отключить в настройках.
- История: что сжато и сколько освобождено, а также уведомления.

Настройки:

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Keep folders compressed — держать папки сжатыми | вкл | Раз в 30 минут сжимать новые файлы в уже сжатых папках |
| Only when plugged in — только на зарядке | вкл | Не работать в фоне от батареи |
| Only after N min without input — после N минут простоя | 5 | Ждать, пока вы не пользуетесь Mac |
| Only when N MB or more are new — порог новых данных | 100 МБ | Не запускаться ради пары мелких файлов |
| Show Steam games automatically — показывать игры Steam | вкл | Показывать установленные игры Steam |
| Open at login — запуск при входе | выкл | Запускать Squeeze при входе в систему |

Настройки хранятся в `~/Library/Application Support/Squeeze/settings.json`.

## Безопасность

- Сжатие без потерь и обратимо, содержимое файлов не меняется.
- Squeeze не трогает папку, пока из неё запущена программа, и не трогает игру Steam, пока Steam её
  устанавливает или обновляет. Это проверяется перед каждой партией, а не только в начале.
- Системные папки, `/Applications`, целые диски, домашняя папка, `~/Library`, iCloud Drive и
  другие облачные папки не принимаются.
- Файлы, которые нельзя сжать (используются, нет прав), остаются как есть.
- Перед распаковкой Squeeze проверяет, хватит ли свободного места.

**Отмена:** нажмите **Decompress**. Папка вернётся к полному размеру, поэтому столько места должно
быть свободно.

## Почему macOS предупреждает

Без предупреждения Apple открывает только программы, подписанные платным Developer ID ($99 в год) и
проверенные Apple (нотаризация). Squeeze бесплатный и пока так не подписан, поэтому macOS один раз
просит его разрешить. Исходный код открыт, и каждая версия собирается из него на GitHub Actions
([журнал сборок](https://github.com/yuran1174/squeeze/actions)).

## Для игроков Steam: скрипт без приложения

Скрипт для Терминала, который делает фоновую часть для игр Steam, если вам удобнее launchd, чем
программа в строке меню. Он берёт инструмент сжатия из Squeeze.app или `afsctool` из Homebrew.

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
./scripts/squeeze-steam.sh --list              # игры, размер на диске, доля сжатого
./scripts/squeeze-steam.sh --app 570 --force   # сжать одну игру сейчас (570 = Dota 2)
./scripts/install-agent.sh                     # раз в 2 часа дожимать новые файлы сжатых игр
./scripts/install-agent.sh --remove            # убрать фоновое задание
```

По умолчанию скрипт трогает только игры, уже сжатые больше чем наполовину, и только на зарядке и в
простое (`--force` отключает две последние проверки). Лог: `~/Library/Logs/squeeze.log`.

## Сборка из исходников

```bash
git clone https://github.com/yuran1174/squeeze && cd squeeze
./scripts/build-afsctool.sh           # инструмент сжатия из его исходников (нужен Homebrew для сборки)
swift test                            # тесты
UNIVERSAL=1 ./scripts/build-app.sh    # dist/Squeeze.app и zip для Apple Silicon и Intel (нужен Xcode)
```

`Sources/SqueezeCore`: сканирование, прогноз, запуск инструмента сжатия, библиотеки Steam, настройки.
`Sources/Squeeze`: приложение в строке меню на SwiftUI. Каждый пуш собирается и тестируется на
GitHub Actions; тег вида `v0.1.0` публикует релиз.

## Ограничения

- Только диски APFS (и HFS+); не exFAT и не сетевые диски.
- Некоторые программы и античиты не любят изменения файлов на диске. Содержимое остаётся прежним,
  но если что-то ведёт себя странно, распакуйте эту папку.
- Интерфейс пока на английском.

## Планы

- Иконка; русский интерфейс.
- Подсказки помимо Steam: другие лаунчеры, бутылки CrossOver и Whisky, большие папки разработчика.
- Общие данные о том, как сжимаются популярные игры и программы.
- Подпись Developer ID и нотаризация: без предупреждения при первом запуске, затем Homebrew cask.

## Лицензия и авторы

Squeeze распространяется под лицензией MIT. Сжатие выполняет [afsctool](https://github.com/RJVB/afsctool)
его собственных авторов под лицензией GPL-3. В Squeeze.app входит его неизменённая копия, собранная
из опубликованных исходников, и запускается как отдельная программа; её лицензии и точный источник
указаны в `Squeeze.app/Contents/Resources/ThirdParty/afsctool`.
